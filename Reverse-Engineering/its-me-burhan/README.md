## Flag
Per-team **dynamic** flag, generated by the CTFd Docker Container Challenge plugin from the pattern:
```
COMPFEST18{bUR_BuR_BUr_buRh4n_h4Un7s_m3_t!L_t0D4y_<ran_16>}
```

## Description
The Adventurers' Guild of Eisenwald runs on an old terminal program, BurhanQuest. Its
guildmaster, the mage **Burhan**, keeps the guild's secrets behind his admin account — and
insists his password "lives in the guild itself, for those who look closely enough."
You're given a wanderer account and a copy of the program. Get in, look closely, and recover
what he's hiding.

Connect (per-team instance via **Fetch Instance**)
Wanderer login: `frieren` / `frieren`

## Deployment
Deployed via the **CTFd Docker Container Challenge plugin** (per-team instances + dynamic flags).

- Build the image:
    ```
    docker build -t itsme-burhan .
    ```
- In CTFd → Admin → Challenges → Create → **Container**:
    - Image: `itsme-burhan`
    - Internal Port: `9000`
    - Command: (empty)
    - Flag pattern: **Random** → `COMPFEST18{bURh4n_h4Un7Ed_M3_f0R_mONtH5_t0_7hE_pO1Nt_wH3Re_I_c4Nt_sL3Ep_wElL_<ran_16>}`
    - Attach `public/burhanquest.jar`
- Players click **Fetch Instance** to spawn their own container.
