# The Last Bitbender
by yrNeh22

---

## Flag
Per-team **dynamic** flag, generated by the CTFd Docker Container Challenge plugin from the pattern:
```
COMPFEST18{0nly_th3_av4t4r_m4st3r3d_4ll_th3m_b1ts_<ran_16>}
```

## Description
who knew Aang could bend bits too?

Connect (per-team instance via **Fetch Instance**)

## Difficulty
medium

## Deployment
Deployed via the **CTFd Docker Container Challenge plugin** (per-team instances + dynamic flags).

- Build the image:
    ```
    docker build -t last-bitbender .
    ```
- In CTFd -> Admin -> Challenges -> Create -> **Container**:
    - Image: `last-bitbender`
    - Internal Port: `9000`
    - Command: (empty)
    - Flag pattern: **Random** -> `COMPFEST18{0nly_th3_av4t4r_m4st3r3d_4ll_th3m_b1ts_<ran_16>}`
    - Attach `dist/chall.exe`
- Players click **Fetch Instance** to spawn their own container.

## Notes
- The container serves the flag from the FLAG env var, which the plugin injects per team.
- Every connection is one request/response exchange, fresh 16-byte nonce, no replay.

## Instance Requirements (Assumption)
- each team must receive its own flag
- each team flag must stay the same when its instance is restarted or recreated
- different team, different flag
- every connection receives a new random request. Only the request changes, the team's flag stays the same
- assuming that the platform provides the flag thru the `FLAG` env var
